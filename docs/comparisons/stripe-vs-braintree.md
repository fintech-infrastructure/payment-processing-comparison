# Stripe vs Braintree (US Businesses, 2026)

| Criteria | Stripe | Braintree |
| --- | --- | --- |
| **Pricing model** | flat_rate | flat_rate |
| **Published rate** | 2.9% + $0.30 | 2.59% + $0.49 |
| **$20k/mo ($50 avg ticket)** | $700.00/mo (3.50%) | $714.00/mo (3.57%) |
| **$100k/mo ($100 avg ticket)** | $3,200.00/mo (3.20%) | $3,080.00/mo (3.08%) |
| **ACH bank debit** | 0.8% (capped at $5.00) | 0.75% (capped at $5.00) |
| **Merchant countries** | 46 | 45 |
| **Tax responsibility** | Merchant handles tax | Merchant handles tax |

- **Stripe:** Developer-first full-stack payment processor with broad APIs, subscriptions, and global card/wallet support. ([Official pricing](https://stripe.com/pricing))
- **Braintree:** PayPal-owned developer gateway combining cards, ACH, Apple Pay, Google Pay, PayPal, and Venmo in one integration. ([Official pricing](https://www.braintreepayments.com/braintree-pricing))
