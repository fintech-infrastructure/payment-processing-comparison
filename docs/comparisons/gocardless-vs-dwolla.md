# GoCardless vs Dwolla (US Businesses, 2026)

| Criteria | GoCardless | Dwolla |
| --- | --- | --- |
| **Pricing model** | flat_rate | custom |
| **Published rate** | 1.0% + $0.25 (capped at $4.00) | Custom ACH API pricing |
| **$20k/mo ($50 avg ticket)** | $300.00/mo (1.50%) | Custom pricing |
| **$100k/mo ($100 avg ticket)** | $1,250.00/mo (1.25%) | Custom pricing |
| **ACH bank debit** | 1.0% + $0.25 (capped at $4.00) | Custom ACH API pricing |
| **Merchant countries** | 30 | 1 |
| **Tax responsibility** | Merchant handles tax | Merchant handles tax |

- **GoCardless:** Bank-to-bank ACH and international direct debit specialist for recurring B2B and subscription invoices (no cards). ([Official pricing](https://gocardless.com/en-us/pricing/))
- **Dwolla:** Developer-focused US ACH and Same-Day ACH bank transfer API (no card processing). ([Official pricing](https://www.dwolla.com/pricing/))
